# 2.2.1 Timing Adjustable

- **Level:** A
- **Automatable:** manual
- **Spec:** <https://www.w3.org/TR/WCAG22/#timing-adjustable>

## Normative text

For each time limit that is set by the content, the user can turn off, adjust, or extend the time limit.
