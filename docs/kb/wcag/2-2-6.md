# 2.2.6 Timeouts

- **Level:** AAA
- **Automatable:** manual
- **Spec:** <https://www.w3.org/TR/WCAG22/#timeouts>

## Normative text

Users are warned of the duration of any user inactivity that could cause data loss, unless the data is preserved for more than 20 hours of inactivity.
