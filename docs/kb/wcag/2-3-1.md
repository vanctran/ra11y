# 2.3.1 Three Flashes or Below Threshold

- **Level:** A
- **Automatable:** manual
- **Spec:** <https://www.w3.org/TR/WCAG22/#three-flashes-or-below-threshold>

## Normative text

Web pages do not contain anything that flashes more than three times in any one second period.
