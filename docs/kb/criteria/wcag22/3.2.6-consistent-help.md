# 3.2.6 Consistent Help

**Level:** A | **Standard:** WCAG 2.2 (new in 2.2)
**Spec:** <https://www.w3.org/TR/WCAG22/#consistent-help>

## Why manual

Help mechanism placement is a site-wide, cross-page property. Static analysis of individual files cannot determine whether help mechanisms appear on multiple pages, what their relative order is across those pages, or whether that order is consistent. No equivalent in WCAG 2.1.

## What to verify

> "If a web page contains any of the following help mechanisms, and those mechanisms are repeated on multiple web pages within a set of web pages, they occur in the same order relative to other page content, unless a change is initiated by the user:
> Human contact details;
> Human contact mechanism;
> Self-help option;
> A fully automated contact mechanism."

Applies only to help mechanisms that are repeated across pages. If a help widget appears on only one page, no consistency requirement applies. "Same order" means the relative position in the DOM/visual order — a chat widget in the bottom-right corner must be in the same relative position on every page where it appears.

## Common failure modes

- Help chat widget appears in the footer on some pages and in the header on others.
- "Contact Us" link in the primary nav on most pages but missing from checkout pages.
- Self-help FAQ link changes position in the page layout across different sections of the site.
- Contact phone number present in the sidebar on product pages but absent on support pages.
- Automated chatbot placement shifts between sidebar and fixed overlay on different pages.

## Attestation guidance

To attach evidence to an `attest` call (`ra11y-kb://criteria/wcag22/3.2.6`):

- Identify all help mechanisms present in the application: contact links, phone numbers, chat widgets, FAQ links, support forms.
- For each mechanism, list every page where it appears and its position relative to surrounding content.
- Confirm position is consistent across all appearances — same relative order in the page structure.
- Note any user-initiated exceptions (e.g., user has collapsed a help panel).

Evidence: cross-page table mapping help mechanism to position on each page, with screenshots confirming consistent placement.
