# 1.4.8 Visual Presentation

**Level:** AAA | **Standard:** WCAG 2.2
**Spec:** <https://www.w3.org/TR/WCAG22/#visual-presentation>

## Why manual

Visual presentation requirements span color, line width, text alignment, line spacing, and resize behavior — properties spread across CSS, user stylesheets, and browser rendering. Static analysis can detect fixed pixel widths or justified alignment in CSS source, but it cannot verify that a user-controllable mechanism exists and works end-to-end across all five conditions.

## What to verify

> "For the visual presentation of blocks of text, a mechanism is available to achieve the following:
> Foreground and background colors can be selected by the user.
> Width is no more than 80 characters or glyphs (40 if CJK).
> Text is not justified (aligned to both the left and the right margins).
> Line spacing (leading) is at least space-and-a-half within paragraphs, and paragraph spacing is at least 1.5 times larger than the line spacing.
> Text can be resized without assistive technology up to 200 percent in a way that does not require the user to scroll horizontally to read a line of text on a full-screen window."

All five conditions must be satisfiable through a mechanism. The content need not implement these values by default — a style-switcher, custom CSS injection point, or browser extension suffices as the mechanism, provided users can reach it.

## Common failure modes

- Text columns wider than 80 characters with no width control available to users.
- Full-justified body text (`text-align: justify`) with no mechanism to switch alignment.
- Line height fixed at `1.0` or `1.2` with no override available.
- `font-size` locked with `!important` or `max-font-size`, preventing 200% resize without horizontal scroll.
- Foreground/background colors hardcoded with `!important`, defeating user stylesheet or high-contrast mode overrides.

## Attestation guidance

To attach evidence to an `attest` call (`ra11y-kb://criteria/wcag22/1.4.8`):

- Record the mechanism available (e.g., style-switcher URL, browser zoom instructions, reading-mode link).
- Confirm each of the five conditions is achievable through that mechanism.
- Test at 200% zoom that body text columns do not require horizontal scrolling.
- Verify `text-align: justify` is absent or can be overridden.
- Note if line-height and paragraph-spacing are at least 1.5× and 2.25× base respectively.

Evidence: screenshot of mechanism in use, plus a style audit showing no `!important` locks on color or font-size.
