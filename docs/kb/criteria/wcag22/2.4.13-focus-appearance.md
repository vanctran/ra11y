# 2.4.13 Focus Appearance

**Level:** AAA | **Standard:** WCAG 2.2
**Spec:** <https://www.w3.org/TR/WCAG22/#focus-appearance>

## Why manual

Focus indicator size and contrast require runtime rendering. The CSS pixel area of the focus ring around the unfocused component perimeter, and the contrast ratio between focused and unfocused states, can only be measured after layout and paint. Static analysis of CSS `outline` properties cannot resolve computed values, applied themes, or browser-default rendering.

## What to verify

> "When the keyboard focus indicator is visible, an area of the focus indicator meets all the following:
> is at least as large as the area of a 2 CSS pixel thick perimeter of the unfocused component or sub-component, and
> has a contrast ratio of at least 3:1 between the same pixels in the focused and unfocused states."

Exceptions: the requirement does not apply when (1) the user agent determines the focus indicator and it cannot be adjusted by the author, or (2) the author has not modified the focus indicator or its background color.

## Common failure modes

- `outline: 1px solid` — below the 2 CSS pixel perimeter-area threshold.
- Focus ring uses the same color as the component background in focused state (contrast ratio < 3:1).
- `outline: none` with a subtle `box-shadow` that does not meet the area or contrast thresholds.
- Focus indicator changes only text color with insufficient contrast between focused and unfocused states.
- Theme switching leaves focus rings with insufficient contrast in dark mode or high-contrast mode.

## Attestation guidance

To attach evidence to an `attest` call (`ra11y-kb://criteria/wcag22/2.4.13`):

- Use browser DevTools to measure the rendered `outline-width` and `outline-offset` on focused elements.
- Calculate the perimeter area: `2 × (width + height) × 2px` minimum in CSS pixels.
- Use a contrast analyser (e.g., APCA or WCAG formula) to compare focused vs. unfocused pixel colors — must be ≥ 3:1.
- Test in both light and dark modes and any high-contrast themes.
- Note exceptions: if the browser default ring is unmodified, no attestation needed for those elements.

Evidence: DevTools screenshots of focus styles for each interactive component, with contrast ratio measurements recorded.
