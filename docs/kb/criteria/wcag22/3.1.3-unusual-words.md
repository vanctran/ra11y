# 3.1.3 Unusual Words

**Level:** AAA | **Standard:** WCAG 2.2
**Spec:** <https://www.w3.org/TR/WCAG22/#unusual-words>

## Why manual

Identifying which words are "unusual" or used in a "restricted way" requires semantic understanding of the content domain. Static analysis cannot distinguish technical jargon from standard vocabulary, recognize idioms, or determine whether a definition mechanism is present and accessible.

## What to verify

> "A mechanism is available to identify specific definitions of words or phrases used in an unusual or restricted way, including idioms and jargon."

"Unusual or restricted way" includes: technical terms with domain-specific meaning, idioms whose literal meaning differs from intent, jargon understood only by specialists, and common words used with restricted meaning (e.g., "token" in authentication contexts). A definition mechanism can be: inline `<dfn>` + `<abbr title>`, a linked glossary, a tooltip, or a definition list.

## Common failure modes

- Technical API documentation using domain terms (e.g., "idempotent", "webhook", "backpressure") without definitions or glossary links.
- Legal text with terms of art (e.g., "indemnification", "force majeure") used without definition.
- Marketing copy using industry jargon without explanation.
- A glossary exists but is not linked from the pages that use the terms.
- `<abbr>` elements present but `title` attribute missing or empty.

## Attestation guidance

To attach evidence to an `attest` call (`ra11y-kb://criteria/wcag22/3.1.3`):

- Audit content pages for domain-specific jargon, idioms, and restricted-use terms.
- Confirm each term has an accessible definition mechanism: `<dfn>`, `<abbr title="...">`, inline definition, or glossary link.
- Verify the glossary or definition is reachable from any page that uses the term.
- Test that `<abbr title>` values are readable by screen readers (VoiceOver/NVDA).

Evidence: list of identified unusual terms per page, definition mechanism used for each, and screen reader output confirming definition is announced.
