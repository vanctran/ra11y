# 2.1.3 Keyboard (No Exception)

**Level:** AAA | **Standard:** WCAG 2.2
**Spec:** <https://www.w3.org/TR/WCAG22/#keyboard-no-exception>

## Why manual

This criterion removes the path-dependent input exception from 2.1.1. Whether a given interaction is path-dependent (e.g., a drawing tool, drag-and-drop, freehand signature) requires runtime behavioral inspection. Static analysis can detect mouse-only handlers, but cannot definitively determine whether the underlying function requires path-dependent movement.

## What to verify

> "All functionality of the content is operable through a keyboard interface without requiring specific timings for individual keystrokes."

No path-dependent exception applies. Every function — including those that rely on mouse drag paths — must have a keyboard equivalent. This supersedes the carve-out in 2.1.1 (SC 2.1.1 permits excluding "the underlying function requires input that depends on the path of the user's movement and not just the endpoints").

## Common failure modes

- Drawing canvas or signature field with no keyboard-accessible alternative.
- Drag-and-drop reordering with no keyboard method (e.g., cut/paste or arrow-key reorder).
- Slider or range control that requires mouse dragging and has no keyboard step increment.
- Custom date picker that requires mouse pointer movement through a calendar grid.
- Spatial game or interactive map that requires pointer path rather than point-and-click.

## Attestation guidance

To attach evidence to an `attest` call (`ra11y-kb://criteria/wcag22/2.1.3`):

- Walk every interactive feature with keyboard only (Tab, arrow keys, Enter, Space).
- Confirm no feature requires mouse movement path to complete — including freehand inputs.
- For drawing or gesture features, verify a keyboard-accessible alternative exists.
- Note any feature where keyboard equivalence is partial or missing — these are failures.

Evidence: screen recording of full keyboard traversal, or a test script (e.g., Playwright) that exercises every interactive widget without mouse events.
