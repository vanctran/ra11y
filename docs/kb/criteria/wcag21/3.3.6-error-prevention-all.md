# 3.3.6 Error Prevention (All) (WCAG 2.1)

**Level:** AAA | **Standard:** WCAG 2.1
**Spec:** <https://www.w3.org/TR/WCAG21/#error-prevention-all>

Identical requirement to `wcag22:3.3.6`. See the canonical entry:
[docs/kb/criteria/wcag22/3.3.6-error-prevention-all.md](../wcag22/3.3.6-error-prevention-all.md)

## What to verify

> "For Web pages that require the user to submit information, at least one of the following is true:
> Submissions are reversible.
> Data entered by the user is checked for input errors and the user is provided an opportunity to correct them.
> A mechanism is available for reviewing, confirming, and correcting information before final submission."

Full attestation guidance: see `wcag22:3.3.6` entry above.
